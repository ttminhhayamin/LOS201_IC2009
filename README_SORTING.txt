Lab 1 & Lab 2 Screenshot Sorting Guide
Basis: LAB01_EmbeddedLinux.docx and LAB02_EmbeddedLinux.docx.
Structure: each practical requirement/question has Input and Output folders.
Input = configuration/source/script/command evidence.
Output = build/runtime/test/result evidence.
Some screenshots are copied into more than one folder when one screenshot clearly covers multiple requirements.
Troubleshooting screenshots are kept under Extra - Troubleshooting and Debugging rather than mixed with final successful evidence.
